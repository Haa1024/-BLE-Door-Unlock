# 共享开门

一键 BLE 蓝牙开门 Android App，适用于住理生活门锁系统。

## 免责声明

本软件仅供学习研究蓝牙低功耗（BLE）通信协议使用，**不会收集、上传或分享任何个人信息**，所有数据仅存储在设备本地。

在使用本软件获取门锁凭证及开门前，请确认你对该门锁设备拥有合法使用权（如已获授权、为合法租户等）。请勿用于非法侵入他人住所或任何违法违规用途。因使用本软件产生的一切后果由使用者自行承担。

## 功能

- 🔓 一键 BLE 蓝牙开门
- 🔄 自动刷新凭证（离线次数用完时自动从服务器获取新 chainKey）
- 🧩 桌面小组件（可拖放调整大小）
- 🔑 住理生活账号登录，自动获取门锁参数
- 📝 支持手动填写凭证参数

## 使用方法

### 1. 编译安装（可选）

如需自行编译：

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

### 2. 配置凭证

**方式一（推荐）**：在设置页登录住理生活账号，点击"自动获取参数"

**方式二**：手动填写设备 ID、项目 ID、凭证 ID、chainKey、MAC 地址

### 3. 开门

点击主界面圆形按钮，或添加桌面小组件一键开门。长按小组件可拖放调整大小。

开门连接、凭证传输或响应异常时，会关闭旧连接并从头自动重试，最多重试 3 次（连同首次尝试共 4 次）。界面和通知会显示当前步骤、失败原因与重试次数。主界面可取消本次开门，最终失败原因会保留，并提供重新尝试的对话框。

凭证过期或离线次数耗尽时，先联网刷新凭证，再重新连接开门。如果服务器报告会话过期，会使用设置中保存的账号密码重新登录，最多进行 3 轮；每轮最多尝试 4 个候选服务器，登录轮数不会在同一次开门任务中重置。凭证刷新网络失败也最多重试 3 次，整个恢复过程最长 150 秒。

手动和自动登录会优先使用上次登录成功的服务器；没有记录时，按原有顺序尝试 `pm.whxinna.com`、`m5-zhuli.whxinna.com`、`p4-zhuli.whxinna.com`、`f5-zhuli.whxinna.com`。服务器不可用或登录失败时继续尝试其余候选地址，仅在登录成功后保存地址；更换账号时清除旧记录。

服务器明确要求额外验证时，提示先在官方 App 完成验证；蓝牙关闭、权限不足、参数无效或未保存登录账号时，提示用户处理。自动重新登录可能使官方 App 的原登录会话退出。已确认开门成功后，凭证更新失败不会触发再次开门。

> 部分手机小组件入口隐藏较深，如真我手机：长按桌面 → 卡片 → 全部卡片 → 滑到底部 → 插件 → 找到「共享开门」。
